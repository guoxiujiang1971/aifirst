AIHandy Privacy Policy

Last updated: June 1, 2026

AIHandy ("the App") is a macOS menu bar AI assistant developed by guoxiujiang. This privacy policy explains how the App handles your data.

Data Collection

AIHandy does not collect, store, or transmit any personal data to servers owned by the developer. Specifically:

  • No analytics or tracking services are included.
  • No crash reporting tools are included.
  • No user accounts or registration are required.
  • No data is sent to any developer-controlled server.

How Your Data Is Processed

The App allows you to send text to third-party AI API endpoints that you configure, such as DeepSeek, Ollama (local), or any OpenAI-compatible API. When you use the App:

  • Text you select and submit for processing (translation, summarization, etc.) is sent only to the API endpoint you have configured.
  • The App does not modify, log, or store this text beyond what is necessary for the current session.
  • Conversation history in the chat feature is stored locally on your device and can be cleared at any time.

API Keys

Any API keys you enter (e.g., DeepSeek API key) are stored locally on your device using UserDefaults. They are never sent to any server owned by the developer.

Accessibility Permission

The App may request Accessibility permission to read selected text from other applications. This permission is used only when you explicitly press a hotkey or click a button. No text is read automatically or without your action.

Third-Party Services

The App communicates only with API endpoints that you manually configure. The developer is not responsible for the privacy practices of those third-party services. Please review their respective privacy policies.

Changes to This Policy

This privacy policy may be updated from time to time. Any changes will be reflected on this page.

Contact

If you have any questions about this privacy policy, please open an issue on the GitHub repository or contact the developer via GitHub: guoxiujiang1971.
